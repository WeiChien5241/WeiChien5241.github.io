GPS-Free Visual Navigation in Corn Fields

Undergraduate Researcher · Advisor: Dr. David Cappelleri · NSF ERC for IoT for Precision Agriculture (IoT4Ag)

  • Validated a GPS-free visual navigation stack in a commercial corn field, achieving 20 consecutive rows of autonomous traversal with zero human interventions at 0.6 m/s under full canopy, and characterized the speed ceiling at which row reacquisition degrades.
  • Implemented a model predictive controller solving an 8-step-horizon constrained optimization each control cycle over a two-state image-space error model, eliminating the need for camera calibration or GPS while enforcing angular-velocity and slew-rate limits for smooth steering.
  • Hand-annotated 574 field images and fine-tuned a DINOv3-based semantic segmentation model to classify traversable ground, crop, and sky, reaching 0.836 mIoU on the lower-camera validation set as the sole perceptual input to the navigation stack.
  • Architected a finite state machine over front and rear cameras coordinating in-row navigation, row-exit detection, odometry-based turning, and reacquisition, using the rear view for exit centering and dead-end recovery.
  • Diagnosed a 12× control-rate variance between GPU and CPU hardware causing false row-exit triggers, and replaced frame-count debouncing with distance-based accumulators to make exit detection platform-independent.
